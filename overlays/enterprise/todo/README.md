# The backlog

What is planned, what is known-broken-but-tolerated, and what is deliberately not
being done. Everything here is a candidate, not a commitment.

## Files

| File | What lives here |
| --- | --- |
| [roadmap.md](roadmap.md) | Where the project is going, in rough order |
| [tech-debt.md](tech-debt.md) | Known compromises in the code, with the reason each was accepted |

## How this relates to issues

They are not duplicates of each other:

- **Issues** are tracked, actionable work — specific enough that a contributor
  could pick it up today, with a reproduction or acceptance criteria.
- **This folder** is thinking-out-loud: direction, half-formed ideas, and debt
  that is real but not yet worth an issue. It is allowed to be vague.

When something here becomes concrete enough to act on, it graduates to an issue.
